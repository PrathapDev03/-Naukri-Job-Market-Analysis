# -Naukri-Job-Market-Analysis

🔍 Naukri Job Market Analysis – Data Science Project

This project is a detailed analysis and machine learning-based exploration of job listings from Naukri.com, aimed at discovering key trends in the Indian job market. It includes everything from data cleaning to predictive modeling and interactive dashboard deployment.

📊 Project Objectives:

Analyze job postings from Naukri.com

Clean and structure data for salary, skills, experience, and location

Perform exploratory data analysis (EDA)

Categorize salaries into High, Medium, and Low

Visualize role demand, top cities, companies, and key skills

Build machine learning models to predict job categories or salary levels

Deploy an interactive Streamlit web application for end users

📁 Dataset Includes:

Job Titles

Companies

Location

Required Skills

Experience

Salary Details

Job Descriptions

🧹 Data Cleaning Process:

Removed missing and duplicate rows

Standardized and categorized salary ranges

Cleaned skills column using string operations

Converted salary values from text to numerical ranges

📊 Visualizations Used:

Job Role vs Demand

Top Hiring Cities and Companies

Skill Frequency Charts

Salary vs Experience Heatmaps

Pie/Bar Charts using Matplotlib, Seaborn, and Plotly

🤖 Machine Learning Models:

Logistic Regression

Random Forest

XGBoost

Feature encoding and model evaluation done using accuracy and classification reports

🌐 Streamlit App (Coming Soon):

An interactive web app where users can:

Filter jobs by skills, cities, and experience

Explore salary and hiring trends

Get insights on in-demand job roles

📌 Key Insights:

Bangalore, Mumbai, and Hyderabad have the highest job openings

Most in-demand skills: Python, SQL, Machine Learning

Companies prefer candidates with 2–5 years of experience for high-paying roles

Data roles are trending across industries
